Разработка минимального бизнес-прототипа для сервиса подбора наращивания волос
1. Определение сегмента и первой победы
Целевой сегмент: начинающие мастера по наращиванию волос (опыт 1-2 года) в Москве и области
Сценарий использования: мастер получает нестандартный кейс от клиента и ищет быстрое решение
Первая победа: получение готового решения по работе с конкретным случаем в течение 15 минут

2. Критические рыночные гипотезы
ТОП-3 гипотезы риска:
- Мастера готовы использовать бесплатный сервис с возможностью доната
- Частные мастера примут рекомендации алгоритма
- Сервис может работать на основе ручной обработки заявок

3. Формат минимального бизнес-прототипа
Выбранный формат: Google-форма + Google-таблица + ручная обработка

Требования к МБП:
- Простая анкета из 5 ключевых вопросов
- База из 10 типовых решений
- Система обратной связи
- Google-документы для хранения кейсов

4. Позиционирование и сообщение
Версия A:
Заголовок: “Бесплатный помощник для мастеров по наращиванию”
Подзаголовки:
- Быстрое решение сложных случаев
- База проверенных методов
Версия B:
Заголовок: “Делимся опытом с начинающими мастерами”
Подзаголовки:
- Сообщество профессионалов
- Готовые решения для сложных ситуаций
- Присоединяйся бесплатно

5. Тактика выхода на рынок
Доступные каналы:
Группы ВКонтакте для мастеров
Телеграм-чаты по наращиванию волос
Личные контакты через школы обучения
Скрипт первого контакта:
“Привет! Мы создаем сервис помощи мастерам по наращиванию. Готовы протестировать его бесплатно? Расскажем, как это работает и соберем ваше мнение.”

6. Воронка привлечения
Шаги воронки:
- Контакт через группы/чаты
- Презентация идеи
- Регистрация в сервисе
- Тестовый кейс
- Сбор обратной связи
