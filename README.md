**NSM (North Star Metric)**: Количество успешно сгенерированных и сохраненных пользователями индивидуальных схем наращивания.

| Период | Цель | Метрика | Целевое значение | Почему это важно |
| :--- | :--- | :--- | :--- | :--- |
| 0–3 месяца | Запустить MVP и проверить гипотезу ценности | Количество используемых генераций схем (B2C) | 10 использований | Подтверждение спроса и работоспособности сервиса. |
| 3–6 месяцев | Привлечь первых B2B партнеров (салоны/мастера) для стабильного дохода | Количество активных B2B подписок | 10 салонов | Валидация модели монетизации |
| 6–12 месяцев | Масштабирование базы пользователей и улучшение точности ИИ | Ежемесячный активный рост пользователей | +15% месяц к месяцу | Демонстрация роста продукта инвесторам/партнерам, накопление данных для дообучения ИИ. |

### Roadmap на 3-6 месяца

| Период | Цель периода | Основные инициативы | Релиз / результат | Метрики успеха |
| :--- | :--- | :--- | :--- | :--- |
| Месяц 1 | Создание рабочего прототипа ядра | Разработка UI загрузки фото, использование предобученных моделей, верстка простого отчета. | Alpha-версия (внутреннее тестирование) | Сервис работоспособен, не возникает ошибок и вылета приложения. |
| Месяц 2 | Техническая интеграция и оплата | Backend API, подключение платежки, настройка аналитики. | Beta-версия (закрытый тест на 20 людях) | Успешная проходимость платежа, корректная запись событий. |
| Месяц 3 | Запуск MVP и первые продажи | Маркетинговый посев, сбор обратной связи. | MVP v1.0 (Публичный запуск) | 10 постоянных использований. |
| Месяц 4–6 | Оптимизация и подготовка к B2B | Улучшение модели на реальных данных, разработка личного кабинета для мастеров, начало outreach-продаж. | Версия v1.5 (B2C + начало B2B) | Конверсия в покупку > 5%, первые 5 пилотных салонов. |

На оставшиеся 6 месяцев - разработка своей модели из собранных данных пользователей.

### Состав команды
| Роль | Основные задачи | Загрузка (FTE) | Есть в команде? | Риск / узкое место |
| :--- | :--- | :--- | :--- | :--- |
| Product Manager / Founder | Видение продукта, приоритизация, общение с пользователями, маркетинг. | 1.0 | Да (Основатель) | Выгорание, расфокусировка между тех частью и маркетингом. |
| AI/ML Engineer | Сбор датасета, обучение модели компьютерного зрения, интеграция модели. | 1.0 | Нет (Найм/Аутсорс) | Критический риск. Сложность найма сильного ML-специалиста в стартап. Возможна замена на no-code AI API + промпт-инжиниринг на старте. |
| Fullstack Developer | Frontend (React/Vue), Backend (Python/Node), интеграция платежей. | 1.0 |Есть (Сооснователь) | Мало опыта работы, невозможность успешно-полноценной работы в одного. |
| UX/UI Designer | Дизайн интерфейса, особенно экранов загрузки фото и отчета. | 0.5 | Нет (Фриланс) | Плохой UX приведет к тому, что пользователи будут делать плохие фото, и ИИ ошибется. |
| Маркетолог (Growth) | Настройка рекламы, посевы, работа с лидерами мнений. | 0.5 | Частично (Founder) | Нехватка компетенций в performance-маркетинге у основателя. |
