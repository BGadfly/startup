# Стартап в информационных технологиях
### Тема: Конструирование продукта. Анализ ситуации рынка. 
Неделя 6.
Команда 2: Петрова Кристина, Коротаева Елена

Используемый стек технологий для MVP:
1. No-Code платформа - фронтенд.
2. Python - бекенд.
   
Функциональные требования:
1. Наличие стартового экрана.
2. Экран с вопросами дял анкетирования.
3. Экран результата с четким названием метода, краткое обоснование ответа, примерные цены.
4. Сохранение результата на почту/фото/файлом.
5. Внедрение ИИ для обработки фотографий.

Нефункциональные требования:
1. Web-first (PWA или адаптивный сайт).
2. Время загрузки страницы (LCP) < 2.5 секунд.
3. Минимальное HTTPS.
4. Кроссплатформенность.
